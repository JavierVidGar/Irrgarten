# Irrgarten

Irrgarten Game Java Project

A Java-based game developed as part of the PDOO subject at UGR.
The project follows an evolutionary development process divided into several assignments (practicas).

## About the Project

**Irrgarten** is a text-based (later graphical) game where players navigate through a labyrinth filled with obstacles and monsters.
The core objective is to survive, collect items, and find the exit while managing health and combat stats.

At the moment, the project is only initialized, nothing has been implemented yet.
The project will compile empty and won't execute anything.

## Tech Stack

**Language:** `Java`
**Build System:** `Apache Ant`
**Version Control:** `Git`

## Getting Started

### Prerequisites

Make sure you have the following installed:
**JDK 17** (or higher)
**Apache Ant**

### How To Build

To compile the project using Ant, run:

```bash
ant compile
```

### How To Run

To execute application:

```bash
ant run
```

### Generating Documentation

```bash
ant javadoc
```
